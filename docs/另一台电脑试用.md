# 安装与运行

Windows 和 macOS 使用相同的源码安装步骤。开始前，请安装 Git、Node.js 22 或更新版本，以及要绑定的 Agent，并确认 Agent 能在本机正常运行。

```bash
git clone https://github.com/z3347212573-cloud/im-link.git
cd im-link
npm ci
npm start
```

Apple 芯片 Mac 建议使用 ARM64 版 Node.js。运行 `node -p process.arch`，确认输出为 `arm64`。`npm ci` 会为当前系统安装依赖和 Electron。

## 首次连接

1. 在飞书开放平台创建自建应用，启用机器人能力，设置消息收发权限和长连接事件订阅，然后发布应用。
2. 打开接线台，选择「添加渠道」，填写机器人凭据并绑定本机 Agent。
3. 重启对应 Agent，在飞书私聊向机器人发送「你好」，确认能收到回复。

更多功能和支持范围见[项目 README](../README.md#支持范围)。

## 更新与排查

- 更新源码后，在项目目录运行 `npm ci`，再用 `npm start` 打开接线台。Agent 侧组件会在对应 Agent 重启后加载更新。
- 如果机器人没有回复，先确认 Agent 能独立运行，再检查飞书的应用发布状态、消息权限和长连接配置。
- 提交问题时请附上操作系统、Node.js 与 Agent 版本、复现步骤和脱敏报错。[提交 Issue](https://github.com/z3347212573-cloud/im-link/issues)

## 本机配置

接线台将配置、会话及加密凭据保存在用户目录下的 `.im-link`。Windows 使用当前用户的 DPAPI，macOS 使用系统钥匙串保护加密密钥。换用其他电脑时，请在接线台重新填写机器人凭据。跨电脑同时运行时，建议为每台电脑配置独立的测试机器人。
