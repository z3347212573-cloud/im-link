# 界面设计

工作名称：接线台 / IM Link。首页的任务是让用户看清“机器人接到了谁”，并直接完成接入与更换。

视觉采用接线台的连接关系作为主要元素：一行中的渠道端与 Agent 端由细线相连，状态位在线上；不以装饰性的统计卡片代替绑定关系。

颜色：雾蓝背景 #EEF2F6、白色工作面 #FFFFFF、深海文字 #19354A、连接蓝 #245FEA、运行青 #167D78、等待琥珀 #A46914。明暗和文字同时表达状态。

字体：标题使用系统圆润人文无衬线（Windows 为 Segoe UI，macOS 为 SF）；正文采用系统中文字体；路径与版本采用系统等宽字体。避免在线字体依赖。

布局：窄侧栏负责渠道、Agent 与操作记录；主工作面展示实际绑定列表；右侧详情解释选中对象和下一步。添加机器人使用分步对话框，包括指引、参数、绑定目标和配置检查。

默认使用真实空状态和本机发现结果，不预置虚构在线机器人。尚未验证的接入明确显示对应步骤；凭据验证与通信验证分开。
