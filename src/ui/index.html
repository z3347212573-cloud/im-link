使用飞书自建应用机器人

已有机器人？直接进入下一步填写参数。

  1. 创建企业自建应用

    在飞书开放平台创建应用，在“应用能力”中添加机器人。

  2. 开启消息和图片权限

    授予接收单聊消息、发送消息和上传／下载图片资源的权限，订阅“接收消息”事件。

  3. 选择长连接接收事件

    无需公网回调地址。按飞书提示发布应用，确保你可以私聊机器人。

  4. 取得接入信息

    在“凭证与基础信息”中复制 App ID 和 App Secret。

ⓘ

保存绑定后会安装 Agent 侧接入配置。涉及主进程时，请按提示手动重开 Agent；保存配置后仍需实测消息和回复。
