# 接线台 · IM Link

接线台是一款桌面工具，把飞书机器人接到你电脑上运行的 DSH 或 Claude Code。你可以在飞书私聊里发文字或图片，让 Agent 在本机处理任务，结果会发回同一个私聊。

接线台窗口用于配置和管理绑定。配置完成后可以关闭窗口，消息由随 Agent 启动的组件处理。

## 支持范围

| 项目 | 公开 `main` 分支的支持范围 |
| --- | --- |
| 操作系统 | Windows、macOS，建议从源码运行 |
| 聊天渠道 | 飞书自建应用机器人，支持一对一私聊 |
| Agent | DSH、Claude Code |
| 消息 | 文字、图片、图文消息，支持图片回复 |

当前为开发版。图片链路已通过隔离测试，实际收发取决于飞书应用权限、所选模型的图片输入能力和 Agent 的启动入口。具体覆盖情况见[验证记录](docs/验证结果.md)。

## 快速开始

准备 Git、Node.js **22 或更高版本**、能在本机正常运行的 DSH 或 Claude Code，以及一个飞书自建应用。然后在终端运行：

```bash
git clone https://github.com/z3347212573-cloud/im-link.git
cd im-link
npm ci
npm start
```

1. 在飞书开放平台为自建应用启用机器人能力，配置消息收发权限，并使用长连接订阅「接收消息」事件。更新应用配置后发布版本。[飞书开放平台教程](https://open.feishu.cn/document/home/develop-a-bot-in-5-minutes/create-an-app)
2. 在接线台点击「添加渠道」，填写飞书 App ID 和 App Secret，选择要绑定的 Agent。
3. 保存后从平时使用的入口重启对应 Agent，再向飞书机器人私聊发送「你好」。收到回复后即可在同一私聊继续交互。

## 日常使用

- **独立会话**　每个私聊有自己的 Agent 会话。发送 `/new` 可以在当前任务完成后新建会话。
- **交互确认**　Agent 的提问和操作审批会发回原私聊，按提示回复即可。如果 `/new` 已排队，使用 `/reply 你的答案` 回答旧会话的提问。
- **图片输入**　直接发送图片，或发送包含图片的富文本消息。支持 PNG、JPEG、GIF 和 WebP，每条最多 4 张，每张最多 5 MiB。飞书应用需要读取消息资源的权限，所选模型需要支持图片输入。
- **图片回传**　让 Agent 把图片保存到渠道的工作目录，在最终回复中使用 `![说明](图片路径)`。机器人会上传图片并发回原私聊，飞书应用需要图片上传权限。

日常收发需要电脑联网，并保持绑定的 Agent 或其接入组件运行。机器人凭据加密保存在本机 `~/.im-link`，会话和临时图片也保存在本机数据目录。
